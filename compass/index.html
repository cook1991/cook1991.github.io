A free compass for Android, with no ads and no tracking.

How to install

  1. Tap Download for Android above.
  2. Open the downloaded TrueNorth-1.3.apk file (check your notifications or Downloads).
  3. If Android warns about installing unknown apps, tap Settings and turn on Allow from this source, then go back and tap Install. If Google Play Protect says it doesn't recognize the developer, tap More details, then Install anyway.
  4. Open TrueNorth. If you want True North instead of Magnetic North, allow location when it asks. Otherwise you can skip that.

What you get

  • Clear heading. An analog compass with a big readout, such as 047° NE.
  • Magnetic or True North. Switch between them whenever you like.
  • Smooth needle. It eases through north instead of spinning the long way round.
  • Calibration help. Tells you to wave the phone in a figure-8 when the sensor needs it.
  • Stays on. The screen stays awake while you're using it.

Your data

TrueNorth has no internet permission, so it can't send anything off your phone. Location is optional and only used for True North, from the last position your phone already knows, with no continuous GPS.

Android only. This app can't be installed on an iPhone. Your phone needs a magnetometer (compass sensor), which most phones have.
