How to install

  1. Tap Download for Android above.
  2. Open the downloaded SpritzStore-1.12.apk file (check your notifications or Downloads).
  3. If Android warns about installing unknown apps, tap Settings and turn on Allow from this source, then go back and tap Install. If Google Play Protect says it doesn't recognize the developer, tap More details, then Install anyway.
  4. Open SpritzStore and tap Install next to an app. If Android says SpritzStore isn't allowed to install apps, turn on Allow from this source, or tap Grant install permission in SpritzStore's Settings. Then confirm the install.

What you get

  • Install in one place. Browse the SpritzLive apps and install any of them with a tap, without Google Play.
  • Updates itself and your apps. Checks about twice a day and can notify you when an update is ready.
  • Checks every download. A downloaded file has to match the checksum published for it before it's offered for install.
  • You stay in charge. Android asks you to confirm every install, and nothing installs silently.
  • No account. Just install it and pick the apps you want.

Your data

SpritzStore has no analytics. It checks the versions of the apps on its list so it can compare them with what's published, and it only talks to GitHub, where the apps are hosted.

Android only. This app can't be installed on an iPhone. This is the one app you install by hand. After that, SpritzStore handles its own updates. See all the apps.
