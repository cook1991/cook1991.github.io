How to install

  1. Tap Download for Android above.
  2. Open the downloaded SecureMessenger-0.2.apk file (check your notifications or Downloads).
  3. If Android warns about installing unknown apps, tap Settings and turn on Allow from this source, then go back and tap Install. If Google Play Protect says it doesn't recognize the developer, tap More details, then Install anyway.
  4. Open Secure Messenger and pair with the other person using a QR code or voice code.

What you get

  • End-to-end encrypted. Messages are encrypted on your phone and can only be read on the other phone.
  • Direct when possible. Phones try to connect straight to each other, which works well on Wi-Fi.
  • Relay as a backup. When a direct connection fails, the relay passes along encrypted data it can't read, and briefly holds it in memory if the other phone is offline.
  • Pair in person or by voice. Confirm who you're talking to with a QR code or a code read aloud.

Your data

The relay never sees message content and doesn't save messages to disk. The camera is only for scanning pairing QR codes.

Invite only. The relay only accepts the people it's set up for, so this app won't work normally for anyone else. Don't install it unless you've been invited. It needs an Android phone with a 64-bit processor and can't be installed on an iPhone.
